# 지출결의서 증빙 만들기

영수증 사진을 넣으면 **금액을 자동으로 읽어** 「지출결의서 증빙」 워드 문서를 만듭니다.
합계와 영수증 매수는 프로그램이 계산하므로 손으로 더할 필요가 없습니다.

같은 일을 하는 두 가지가 있습니다.

| | 웹앱 | 윈도우 프로그램 |
|---|---|---|
| 쓰는 법 | 주소를 열면 끝 | `.exe` 를 받아 실행 |
| 설치 | 필요 없음 | 필요 없음 (단일 파일) |
| 판독 | Tesseract (WebAssembly) | 윈도우 내장 OCR |
| 금액 정확도 | 10/12 (83%) | 11/12 (92%) |
| 고쳤을 때 | 새로 고침하면 반영 | 새 파일을 다시 나눠 줘야 함 |
| 인터넷 | 처음 한 번만 필요 | 필요 없음 |

**두 경우 모두 영수증 사진은 사용자의 컴퓨터를 벗어나지 않습니다.** 웹앱도 판독과
문서 생성을 전부 브라우저 안에서 하며, 서버로 아무것도 보내지 않습니다.

---

## 웹앱 쓰는 법

1. 주소를 엽니다 (배포 후 이곳에 적을 것)
2. 영수증 사진을 끌어다 놓거나 **Ctrl + V** 로 붙여넣습니다
3. **지출인**을 입력합니다
4. **[영수증 읽기]** — 한 장에 4초쯤 걸립니다
5. **금액을 영수증과 대조하고 ⚠ 를 눌러 확인 처리합니다**
6. **[워드 문서 만들기]** — 파일이 내려받아집니다

> 처음 한 번은 한국어 판독 데이터(12MB)를 내려받느라 시간이 걸립니다.
> 그다음부터는 브라우저가 기억해 두므로 빠릅니다.

### 문서 모양

문서 한 장은 **왼쪽 쪽 / 오른쪽 쪽**으로 나뉘고, 한 쪽에 영수증 **6장까지** 들어갑니다.
쪽 번호는 1~10이며 두 쪽이 모여 한 장이 됩니다(1·2쪽 → 1장, 3·4쪽 → 2장 …).
따라서 최대 **60장, 문서 5장**까지 만들 수 있습니다.

영수증을 옮기려면 표의 **'쪽' 칸에 번호를 넣거나** 아래 **[◀ 앞쪽으로] [뒤쪽으로 ▶]** 를
씁니다. 한 쪽이 6장으로 차면 더 넣지 못하게 막고 알려 줍니다.

### 자동 판독은 얼마나 맞나

실제 영수증 12장으로 잰 결과입니다.

| | 웹앱(Tesseract) | 윈도우판(내장 OCR) |
|---|---|---|
| 금액 | 10/12 | 11/12 |
| 날짜 | 11/12 | 11/12 |
| 정답이 후보에 있음 | 11/12 | 12/12 |

총액을 잘못 골랐더라도 **정답은 대개 후보 안에 있습니다.** 금액 칸을 누르면 영수증에서
읽은 숫자들이 목록으로 나오므로 거기서 고르면 됩니다.

**금액의 최종 확인은 사람이 합니다.** 확인하지 않은 금액이 하나라도 남아 있으면
문서를 만들지 않습니다. 회계 문서이므로 일부러 그렇게 막아 두었습니다.

## 개발

```bash
# 웹앱 — 서버가 필요합니다(모듈을 파일로 직접 열면 브라우저가 막습니다)
python -m http.server 8765 --directory web

# 윈도우판
python -m pip install -r requirements.txt
python src/main.py
```

### 고친 뒤 반드시 돌릴 것

두 판이 **같은 문서**를 만들어야 합니다. 한쪽 규칙만 고치면 결과가 어긋납니다.

```bash
python web/검증/기준만들기.py     # 파이썬으로 기준 문서 생성
# 브라우저에서 web/검증/대조.html 을 열고 대조실행() 실행
python web/검증/대조하기.py       # 두 문서를 항목별로 견줌
```

판독을 건드렸다면 `web/검증/채점.html` 로 정확도를 다시 재고, 윈도우판은
`python 실측/재현검증.py` 로 원본 3건이 그대로 재현되는지 확인합니다.

자세한 구조와 그동안 겪은 함정은 [CLAUDE.md](CLAUDE.md) 에 적어 두었습니다.
